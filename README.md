# Estudo de caso: requisitos de um serviço público digital

Projeto fictício que mostra, de ponta a ponta, como transformo uma necessidade de negócio em requisitos claros, protótipo navegável e testes: **Agendamento de Coleta de Entulho** da "Prefeitura de Vila Modelo".

> Todos os dados, nomes e regras são inventados. Nada aqui vem de órgão ou cliente real.

Em construção. Conteúdo previsto:

- [`docs/`](docs): especificação de requisitos, histórias de usuário, regras de negócio e rastreabilidade
- [`prototipo/`](prototipo): protótipo navegável em HTML, CSS e JavaScript, com testes automatizados
